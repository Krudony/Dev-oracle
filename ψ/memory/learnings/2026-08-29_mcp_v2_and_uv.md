# MCP SDK 2.x and UV Non-Interactive Patterns

**Date**: 2026-08-29
**Source**: rrr: REPO

## Context
During the creation of a DIY ChatGPT Web MCP Bridge PoC using Python.

## The Lesson
1. **MCP SDK 2.x Migration**: In the `mcp` Python SDK version 2.x, the `FastMCP` class has been renamed to `MCPServer`. Imports should change from `from mcp.server.fastmcp import FastMCP` to `from mcp.server.mcpserver import MCPServer`.
2. **UV Virtual Environments**: When using `uv venv` in non-interactive agent workflows, it may prompt for confirmation if a `venv` already partially exists or if it detects conflicts. Always use `uv venv --clear venv` (or pass `-y` / `--clear`) to avoid blocking background tasks.
3. **Maw Hey Target Resolution**: When sending cross-node messages with `maw hey`, the exact target (e.g., `jarvis-node:chatgptmcp`) must be specified if the target is not a registered local daemon or simple name. Do not assume bare names like `jarvis-oracle` will route correctly across nodes without the correct node prefix.
