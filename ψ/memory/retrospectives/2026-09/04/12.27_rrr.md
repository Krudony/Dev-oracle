## Learned
- **Module-Load Snapshot Hazard**: Exporting static configuration objects evaluated from `process.env` at module import time prevents test harnesses from overriding settings and causes silent failures. Using factory functions (`getConfig()`) and dynamic `Proxy` wrappers preserves backward compatibility while allowing dynamic runtime resolution.
- **Test Harness Header Delegation**: Pre-writing HTTP response headers in mock test servers breaks error testing. Always let custom handlers control status and headers, reserving default headers solely for the unhandled fallback path.
- **Single-Tab AI Bridge Isolation**: When interacting with browser-based AI bridges with a single global tab, server-side concurrency mutexes with immediate HTTP 409 rejection are required to prevent cross-request document and prompt leaks.
- **Strict Binary Signatures**: Client-provided MIME types cannot be trusted. Validating binary magic bytes in memory provides true defense against file smuggling.
