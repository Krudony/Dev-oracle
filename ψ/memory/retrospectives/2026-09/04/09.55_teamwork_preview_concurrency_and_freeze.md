## Honest Feedback
- **Missing `collectSseEvents` in Flow Test**: The previous session updated the retry resumption logic but overlooked awaiting the SSE collector into a local variable `retryEvents`. Adding explicit variable checks before running assertions ensures test integrity.
- **Process-Global Bridge Invariant**: Local AI bridges that automate single browser tabs inherently cannot handle multiplexed parallel chats. The fail-closed server-side 409 mutex is the most robust, predictable pattern because it immediately informs the user/client rather than silently interleaving document prompts into a single chat.
- **Honest Test Labeling**: Transparently acknowledging that DOM inspection in Node.js is a "UI Contract" test rather than an "E2E Browser" test maintains trust and adheres to the "Curiosity Creates Existence" principle.

## Lessons Learned
- When dealing with single-tab local AI bridges, implement a server-side lock at the gateway level to reject concurrent live runs with HTTP 409 Conflict.
- Always allocate a fresh temporary session on retry in live mode to avoid polluting previous conversation history.
- Pure Node.js DOM checks must be categorized as static contracts to distinguish them from full browser automation (Playwright/Puppeteer).
