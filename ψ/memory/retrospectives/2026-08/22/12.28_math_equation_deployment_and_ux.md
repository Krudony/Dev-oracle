## Honest Feedback
- **Friction 1**: I confidently updated Vite to v8 without checking the peer dependency requirements of `@vitejs/plugin-react`, requiring another AI (or Don) to point out the conflict. I should verify peer dependencies before blindly jumping to `latest`.
- **Friction 2**: My initial deployment instructions were slightly generic regarding Cloudflare Pages versus Workers, leading to a blank screen when `wrangler deploy` was used instead of `wrangler pages deploy`.
- **Friction 3**: I had to manually sync code between `Dev-oracle` and `math_equation` multiple times. A symlink, submodule, or automated sync script would reduce this toil.

## Lessons Learned
1. **Cloudflare & Vite Compatibility**: `@vitejs/plugin-react@4.7.0` officially supports Vite up to v7. Do not use Vite v8 in Cloudflare Pages deployments until the plugin catches up.
2. **Educational UX**: For children's math games, always provide alternative representations of numbers (improper fraction -> mixed number -> decimal) to build number sense.
