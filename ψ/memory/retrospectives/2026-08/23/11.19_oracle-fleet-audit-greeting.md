## 💭 Honest Feedback

- Finding out the active status of agents requires manual checking of tmux/processes since `maw overview` did not list them.
- Direct tmux key injection is unstable if the target pane is in the middle of writing a prompt or running a tool, causing keys to be sent in the wrong context.
- The lack of a centralized status endpoint or CLI verb for live process tracking creates friction when checking fleet status.

## Lessons Learned

- **Pattern**: When testing multi-agent communication, verify the target's interactive terminal state before injecting raw keys to prevent disrupting running tasks.
- **Mistake**: Trying to use `maw talk-to` on an offline target agent without checking its port availability first.
